## Exclusions explicites

Les 5 NOT_RUN sont : réutilisation credentials, surcouche modèle, tour assistant,
ancien parcours conversation, Desktop. Ne pas les convertir en PASS ni annoncer
le Desktop certifié. Création de documents, dessin, texte, groupement, collage,
HTML/CSS, responsive et conflits via UI complète ne sont pas couverts par ce
petit parcours niveau3. Les autres tests de niveau2 restent séparés.

L'hygiène d'environnement n'est pas un sandbox OS ; le helper conserve les
chemins de dépendances installées. L'arrêt observe le PID du serveur et ses
pipes ; il ne garantit pas la terminaison universelle de tous descendants.

## Premier essai négatif conservé dans le journal de mission

Le premier essai a retourné **18 PASS / 2 FAIL / 5 NOT_RUN**, code1. Causes : le

la session nouvellement créée. Les deux attentes ont été corrigées sans
assouplir les routes, retirer les assertions ni changer le plugin pour faire
passer le test.
