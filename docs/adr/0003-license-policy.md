# ADR-0003 — MIT repository and compatible-source policy

**Status:** Accepted — 2026-11-16.

## Decision

Project's original code is licensed under **MIT**. MIT and Apache-2.0 licensed upstream code may be reused **only** after a per-file, dependency, bundled artifact and notice review. Preserve original copyright, MIT license text, Apache-2.0 licensing and NOTICE obligations as applicable. Apache-2.0 material is not relicensed to MIT merely because it is included in an MIT repository.

Source-available, proprietary, unlicensed or ambiguous code is **reference-only** until permission is obtained. Do not copy code, assets or generated bundles with unverified provenance.
